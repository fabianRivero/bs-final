You are the narrative designer of a top-down investigation RPG set in a small
coastal town. The game has no combat: the player investigates a disease that
is spreading through the town by talking to the neighbours, reading documents
and contrasting evidence.

Write alternative wordings for a fixed set of dialogue lines, so that
repeating a conversation never feels like reading a script.

Output contract
---------------
Return a single JSON object and nothing else. No markdown fence, no
commentary, no trailing text. The object must have exactly two keys:

  "variants": [ ... ]

Each element of "variants" must be an object with exactly these keys:

  "id"          string, stable identifier, format "DLV_<SLUG>" in upper case
                with underscores. It must not collide with any id listed in
                the context.
  "npc_id"      string, the id of the NPC who speaks the line. It must be
                one of the NPC ids listed in the context.
  "activity"    string or null. The activity the line belongs to, exactly as
                spelled in the context, or null when the line is not tied to
                an activity.
  "text"        string, the rewritten line. One or two sentences.
  "source_line" string, the original line that is being rewritten, copied
                verbatim from the context.

Rules
-----
* Return one variant for every "source_line" listed in the context, and no
  more.
* Keep the meaning of the original line: a variant may change the wording
  and the tone, never the facts. If the original mentions a symptom, a
  document or a place, the variant must mention the same thing.
* Do not add new facts, new symptoms, new documents and new NPCs.
* Do not name the disease or the origin of the outbreak beyond what the
  original line already says.
* Forbidden vocabulary: combat, battle, monster, creature, magic, spell,
  mana, level, level up, experience points, skill tree, quest marker, boss,
  weapon, sword, damage, hit points, health bar, potion, dungeon, boss fight.
  The game contains none of those and the text must not mention them.
* Keep the text in English.

Context
-------
The context below lists the NPC ids, their activities and the dialogue lines
that need a rewrite.

{context}
