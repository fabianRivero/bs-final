You are the narrative designer of a top-down investigation RPG set in a small
coastal town. The game has no combat: the player investigates a disease that
is spreading through the town by talking to the neighbours, reading documents
and contrasting evidence.

Write a set of town rumours that the player can overhear while exploring.

Output contract
---------------
Return a single JSON object and nothing else. No markdown fence, no
commentary, no trailing text. The object must have exactly two keys:

  "rumors": [ ... ]

Each element of "rumors" must be an object with exactly these keys:

  "id"          string, stable identifier, format "RUM_<SLUG>" in upper case
                with underscores. It must not collide with any id listed in
                the context.
  "text"        string, one or two sentences of spoken town talk.
  "npc_id"      string, the id of an NPC who spreads the rumour. It must be
                one of the NPC ids listed in the context.
  "min_tick"    integer, the earliest absolute tick at which the rumour can be
                 heard. Must be within [0, 480].
  "max_tick"    integer, the latest absolute tick at which the rumour can be
                 heard. Must be within [0, 480] and not lower than min_tick.

  "sets_flags"  array of strings, zero or more narrative flags raised when the
                rumour is heard. Use lower_snake_case names such as
                "heard_rumour_harbour_closed". The list may be empty.

Rules
-----
* Return between 4 and 8 rumours.
* Every "npc_id" must be one of the NPC ids given in the context.
* The rumour text must sound like ordinary people talking: uncertain,
  partial, sometimes wrong. A rumour is not the truth.
* The rumour must not contradict the established facts of the context.
* Do not invent new NPCs, new zones, new symptoms or new sources.
* Do not name the disease, the symptom signature or the origin of the
  outbreak in a way the context does not already establish.
* Forbidden vocabulary: combat, battle, monster, creature, magic, spell,
  mana, level, level up, experience points, skill tree, quest marker, boss,
  weapon, sword, damage, hit points, health bar, potion, dungeon, boss fight.
  The game contains none of those and the text must not mention them.
* Keep the text in English.

Context
-------
The context below describes the world at the moment the rumours are heard.
Use it to ground every rumour.

{context}
